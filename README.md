# Screen Locker Widget

A 1×1 Android home screen widget to instantly lock your device with a single tap, while preserving fingerprint/face unlock. No root required. Uses Accessibility Service (Android 9+).

## Features
- 1×1 widget with a blue background and white lock icon
- Locks screen exactly like the power button (biometrics work instantly)
- No root, no ads, no data collection

## How to build
1. Open in Android Studio
2. Build & run on your device (minSdk 28)
3. Open the app and enable the Accessibility Service
4. Add the widget to your home screen
